# FAXI

가족끼리 차를 탈 때 하는 택시 놀이를 앱으로 만들었습니다. 운전하는 사람이 기사, 옆에 탄 가족이 손님이 됩니다. 요금은 차에서 읽은 값으로 1원까지 계산하고, 실제로 돈이 오가지는 않습니다. 누가 누구에게 얼마를 갚아야 하는지 가족 장부에 적어 둘 뿐입니다.

현대자동차그룹 Pleos Connect 앱 개발 공모전에 내려고 만들었습니다. 차 화면에서 도는 앱과 가족들 폰에 까는 앱, 두 개로 되어 있습니다.

## 시연 영상

[![시연 영상](docs/screenshots/00-video.png)](https://github.com/saejinpark/FAXI/releases/download/v1.0/FAXI-demo.mp4)

Pleos Connect 에뮬레이터(왼쪽)와 폰 에뮬레이터(오른쪽)를 같이 녹화했습니다. 차량 값은 에뮬레이터의 Virtual Console로 넣었고, 화면에 나오는 요금은 녹화하면서 실제로 계산된 값입니다. 화면 녹화에는 소리가 담기지 않아서, 차가 그때 읽은 문장을 맥 음성으로 다시 입혔습니다.

## 어떻게 쓰나

1. 주차한 상태에서 차 화면에서 기사와 손님을 고릅니다. 손님 폰에 뜨는 4자리 숫자를 차에 눌러야 미터기가 켜집니다. 손님에게 밀린 돈이 있으면 차가 먼저 말로 독촉합니다.
2. 달리는 동안 차 화면에는 기사 자격증, 손님, 손님이 폰으로 보낸 한마디, 요금이 붙는 옵션(에어컨, 엉따, 와이퍼, 창문)이 떠 있습니다. 얼마가 나왔는지는 내릴 때까지 모릅니다.
3. 기어를 P에 넣으면 하차입니다. 그때 영수증을 한 번에 보여 주고 요금을 읽어 줍니다. 기사는 차 화면에서 손님을 평가하고, 손님은 영수증 QR을 폰으로 찍어 저장한 뒤 폰에서 기사 후기를 남깁니다. 후기는 다음에 그 기사를 고를 때 차가 읽어 줍니다.
4. 갚을 돈은 장부에 쌓입니다. 보냈다고 적으면 받는 사람이 확인하고, 안 받았다고 하면 "다시 확인"으로 남겨서 둘이 이야기해 보게 합니다. 생일에는 탕감도 됩니다.

## 요금표

서울 택시 요금을 흉내 냈고, 가족 택시라서 옵션 요금을 더했습니다.

| 항목 | 요금 | 어디서 읽나 |
| --- | --- | --- |
| 기본요금 | 4,800원 | 탑승 인증 |
| 거리요금 | 132m마다 100원 | 주행거리계, 속도 |
| 대기요금 | 31초 서 있을 때마다 100원 | 속도 |
| 심야 할증 | 밤 10시~새벽 4시 20% | 시계 |
| 우천 할증 | 와이퍼가 도는 동안 10% | 와이퍼 |
| 냉난방 | 1분에 30원 | 공조 |
| 엉따 | 조수석 열선 1분에 20원 | 시트 |
| 창문 | 열려 있는 1분에 10원 | 창문 |
| 경유지 | 1곳 500원 | 내비 |
| 급정거 | 1번에 50원 돌려줌 | 속도 변화 |

밀린 돈에는 이자가 붙지 않습니다. 다음에 탈 때 요금에 합쳐지고, 차가 며칠째인지 알려 줄 뿐입니다. 기사가 손님에게 갚을 돈이 있으면 이번 요금에서 먼저 빼 줍니다. 아직 운전을 못 하는 아이가 탄 요금은 청구하지 않고 평생 장부에 쌓아 둡니다.

## 쓴 SDK

- Pleos Vehicle SDK: 주행거리, 기어, 공조, 시트 열선, 와이퍼, 창문
- Pleos TextToSpeech SDK: 인사, 요금 안내, 독촉, 후기 읽기. 차 안 엔진(ON_DEVICE)으로 읽어서 이름과 금액이 차 밖으로 나가지 않습니다.
- Pleos NaviHelper SDK: 출발지, 도착지, 경유지
- Android Car API: 속도, 주행 상태

## 서버가 없습니다

장부는 차 안에만 있습니다. 가족마다 비밀 열쇠가 하나씩 있고, 처음에 차 화면의 초대 QR을 폰으로 찍어 받아 갑니다. 탑승 코드는 이 열쇠로 만드는 OTP라서 인터넷이 필요 없습니다. 손님 한마디와 기사 후기는 같은 Wi-Fi(차 핫스팟)에서 폰이 차로 직접 보내고, 같은 열쇠로 서명해서 다른 사람이 흉내 낼 수 없습니다. 영수증은 차 화면 QR로 폰에 옮깁니다.

## 실행 방법

APK는 [`apk/`](apk) 폴더에 있습니다. [릴리스 v1.0](https://github.com/saejinpark/FAXI/releases/tag/v1.0)에도 같은 파일이 있습니다.

| 파일 | 설치할 곳 |
| --- | --- |
| `박세진_FAXI_release.apk` | 차: Pleos Connect 에뮬레이터 (시스템 이미지 `pleos_car_emulator`, Android 14) |
| `박세진_FAXI-phone_release.apk` | 폰: Android 9 이상 기기나 에뮬레이터 |

1. 두 에뮬레이터에 각각 APK를 설치합니다(`adb install -r <파일>`).
2. 폰 앱에서 "엄마 · MAXI로 등록"을 누릅니다. 차 앱에 처음부터 들어 있는 시연 가족과 같은 열쇠를 씁니다.
3. 차 앱 운행 탭에서 기사 "아빠", 손님 "엄마"를 고르고, 폰에 뜬 4자리를 누른 뒤 미터기를 켭니다.
4. 차량 값은 Virtual Console로 바꿉니다. `adb forward tcp:8088 tcp:8088`을 한 뒤 브라우저에서 `http://127.0.0.1:8088/`을 엽니다. 기어를 D로 두고 ACCEL로 달리다가 P에 넣으면 하차합니다. 에어컨, 시트 열선, 와이퍼, 창문 카드를 켜면 요금이 붙습니다.
5. 폰에서 차로 한마디나 기사 후기를 보내려면 차 에뮬레이터에 `adb forward tcp:47800 tcp:47800`을 해 둡니다. 폰 에뮬레이터는 `10.0.2.2`로 차를 찾습니다.
6. 에뮬레이터 카메라로는 차 화면의 영수증 QR을 찍을 수 없습니다. 하차 뒤 `adb logcat -s FaxiReceipt`에 찍힌 `faxi://receipt…` 링크를 폰에서 열면 같은 일이 됩니다.
   `adb shell am start -a android.intent.action.VIEW -d '<링크>' com.geppetto.faxi.phone`

`tools/demo.sh`는 에뮬레이터 두 대를 찾아 위 준비를 한 번에 합니다.

## 빌드

```bash
./gradlew assembleRelease
./gradlew testDebugUnitTest
```

`tools/package.sh`는 테스트를 돌린 뒤 `apk/` 폴더의 두 파일을 새로 만듭니다. 시험한 환경은 macOS의 Android Studio, Pleos Connect 에뮬레이터(API 34), 폰 에뮬레이터(API 37)입니다.

| 모듈 | 내용 |
| --- | --- |
| `app` | 차 앱 |
| `phone` | 폰 앱 |
| `core` | 두 앱이 같이 쓰는 요금 계산, 탑승 코드, QR, 메시지 서명 |
| `design` | 색, 글자, 버튼, 아이콘 |

## 아직 확인 못 한 것

- 실제 차에서는 아직 못 돌려 봤습니다. 에뮬레이터에서만 확인했습니다.
- 폰 카메라로 차 화면 QR을 찍는 것은 실기기로 해 보지 못했습니다(에뮬레이터 카메라로는 차 화면을 찍을 수 없어서 딥 링크로 시험했습니다).
- 차 핫스팟에 붙은 실제 폰이 차로 메시지를 보낼 수 있는지 아직 모릅니다.
